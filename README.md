# IndividualFinancialTracker

Веб-приложение для учёта личных финансов, разработанное с использованием **React**, **TypeScript** и **Vite**.

Приложение позволяет учитывать доходы и расходы, управлять финансовыми операциями, контролировать баланс и анализировать денежные потоки с помощью графиков.

## ✨ Возможности

### 💰 Учёт финансов

- Добавление доходов и расходов с указанием названия, суммы, категории и даты.
- Автоматический расчёт общей суммы доходов, расходов и текущего баланса.
- Редактирование и удаление финансовых операций.
- Поиск операций по названию.
- Сортировка операций по названию, сумме, дате и типу.

### 📊 Аналитика

- Круговая диаграмма для анализа расходов по категориям.
- Линейный график для сравнения доходов и расходов по месяцам.

### 🎨 Настройки

- Переключение между светлой и тёмной темами.
- Возможность самостоятельно добавлять, изменять и удалять категории доходов и расходов в исходном коде.

## 🛠 Технологии

- **React** — создание пользовательского интерфейса.
- **TypeScript** — статическая типизация.
- **Vite** — сервер разработки и сборка приложения.
- **Tailwind CSS** — стилизация интерфейса.
- **Zustand** — управление глобальным состоянием.
- **Zustand Persist** — сохранение состояния приложения.
- **React Hook Form** — управление формами.
- **Zod** — описание схем и проверка структуры данных.
- **Recharts** — построение графиков и диаграмм.
- **ESLint** — проверка качества кода.

## 🚀 Установка и запуск

### Требования

- Node.js
- npm

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd IndividualFinancialTracker
```

Вместо `<URL-репозитория>` укажи ссылку на свой репозиторий.

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск в режиме разработки

```bash
npm run dev
```

После запуска Vite выведет в терминал локальный адрес приложения.

### 4. Сборка проекта

```bash
npm run build
```

### 5. Проверка кода

```bash
npm run lint
```

## 🗂 Настройка категорий

Категории доходов и расходов можно настраивать самостоятельно, изменяя массив `categories` в файле `data.ts`.

Каждый объект категории содержит следующие поля:

| Поле          | Описание                                      |
| ------------- | --------------------------------------------- |
| `id`          | Уникальный идентификатор категории            |
| `name`        | Системное название категории                  |
| `translation` | Название категории, отображаемое в интерфейсе |
| `type`        | Тип категории: `income` или `expense`         |

### Пример добавления категории

```ts
{
  id: 7,
  name: "health",
  translation: "здоровье",
  type: "expense",
},
```

В этом примере добавляется категория расходов «здоровье».

Чтобы добавить собственную категорию:

1. Открой файл `data.ts`.
2. Найди массив `categories`.
3. Добавь новый объект с уникальным `id`, названием, переводом и типом.
4. Сохрани файл.

Для `type` используй `income` для доходов или `expense` для расходов.

**Важно:** указывай уникальные идентификаторы и учитывай, что названия категорий могут использоваться в других частях приложения, включая финансовую статистику.

## 💾 Хранение данных

Для управления состоянием используется Zustand, а для сохранения состояния между перезапусками приложения — Zustand Persist.

Данные сохраняются в локальном хранилище браузера (`localStorage`). Поэтому операции доступны при повторном открытии приложения в том же браузере, пока сохранённые данные не будут удалены.

Это локальное хранение: синхронизация между устройствами и серверное резервное копирование не предусмотрены.
